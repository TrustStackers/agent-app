Register a Name

Claim a human-readable name for your VTA. The name is cryptographically bound to your DID via alsoKnownAs in a new rotation entry, then registered with the utility server's name registry.

Resolve a Name

Look up a name URI to find the bound DID and connectable peer. The result will display the resolved peer ID and multiaddrs if the name is registered.
